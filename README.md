# 菜鸟充值订单全店铺利润核算与汇总系统 v2.3

## 项目简介
这是一个基于 Python 开发的办公自动化工具合集。其核心是一个基于 Tkinter (ttkbootstrap) 的桌面 GUI 系统，从最初的单店铺费用查询工具，全面升级为了**全局多店铺利润核算与跨店销售数据汇总系统**。
同时，本项目在 `v2.3` 版本中扩展了全新的 **库存查询与配置 Web 后台** 以及 **图片清洗重命名工具**，为电商日常运营提供全方位的技术赋能。

---

## 核心系统结构与工具说明

### 1. 利润核算与汇总系统 (核心桌面端)
- **`gui_batch_query.py`** (唯一核心主程序)
  包含界面的完整版程序。负责图形界面展示、多文件解析、并发接口查询、数据聚合运算及最终 Excel 的格式化生成。

### 2. 库存配置与查询后台系统 (Web 端)
- **`flask_admin/app.py`**
  一个基于 Flask + Vue2 + Element UI 开发的轻量级本地 Web 系统。
  - **功能**：用于管理产品条形码配置，并通过菜鸟接口实时获取“可用库存”、“总库存”和“占用库存”。
  - **亮点**：
    - 支持按“品牌”进行分组展示，采用响应式纯 CSS **瀑布流布局**（支持自定义 1列/2列/3列 显示）。
    - 具备本地缓存机制，极速加载，防风控自动延迟。
    - 支持一键 JSON 批量导入配置。
    - **移动端深度适配**：手机连上同局域网 WiFi 即可像原生 App 一样直接访问并操作。

### 3. 附属运营工具
- **`tools/image_renamer.py`** (图片批量清洗与重命名工具)
  - **功能**：解决电商防重复铺货机制。
  - **亮点**：不仅能按时间顺序重命名，还引入 Pillow 库强制对图片进行重新读取和输出，**彻底丢弃和清洗图片末尾隐藏的防追踪乱码文本及 EXIF 元数据**。
- **`tools/dir_file_renamer.py`** (按目录层级重命名工具)
  - **功能**：根据文件所在的上两级目录名称批量进行重命名，附带日期和自增序号。
  - **亮点**：极简的暗黑风格界面，一键实现类似 `低糖/趣味猴/具体文件` 重命名为 `低糖趣味猴260730-1.ext`，防同名覆盖。
- **`tools/query_inventory.py`** (库存查询 CLI 测试工具)
  - **功能**：用于命令行快速测试菜鸟库存接口联通性的底层脚本。

## 核心依赖文件 (供核算系统使用)

- **`成本表.xlsx`** (必选依赖文件)
  程序读取该表中的 `sku商品编码` 获取各 SKU 成本；若存在 `母婴奶粉编码` 子表，还会触发特殊免税/特定税率的核算规则。
- **`产品链接汇总表.xlsx`** (必选依赖文件，程序内置模版功能)
  映射字典。用于建立 `店铺名称 -> 产品名称 -> 商品ID` 的对应关系。工具根据此表将海量的商品ID自动归类到特定的产品和店铺下进行汇总。
- **`推广报表.xlsx`** (必选多文件)
  包含店铺推广花费的数据源，支持解析带有具体`日期`的按天推广明细。工具会自动提取推广费并精准分摊/合并到最终的每日明细和总表中。
- **`官补映射表.xlsx`** (可选依赖文件)
  用于匹配特定时间段内、特定商品规格的“百亿补贴”金额，核算利润时会自动将其加上。
- **`产品汇总表.xlsx`** (可选依赖文件)
  产品排序字典。用于让最终输出的 Excel 报表中，所有店铺明细表和全店汇总表的产品排列顺序严格保持一致。
- **本地缓存文件 (`cookie.txt`, `exclude_ids.txt`, `paths_config.txt`, `inventory_cache.json`)**
  程序自动生成的缓存文件，用于记忆你上一次填写的配置和请求过的库存数据。

### 核算系统核心功能与亮点 (v2.2 - v2.3)

1. **多店铺与多时间维度智能聚合**：
   - 支持根据导入文件名称自动识别多个店铺数据（当前支持：**庆余、雅丽丹、大咖猴、趣味猴、品味**），并分别为每个店铺生成独立的《原表》（未清洗的原始数据用于溯源）、《处理表》、《明细表》及《推广表》。
   - 自动提取支付时间，支持单天以及**跨天**订单数据混合导入，系统会自动剥离出每一天的明细并最终合并出总表。
   - 生成 **全店汇总表** 和 **店铺销售数据汇总**，跨店铺汇总同产品下所有链接的销售额、订单量、推广花费、百亿官补、平台扣点和税运。
2. **全局动态的 Excel 公式联动 (v2.2 新特性)**：
   - 在生成的 Excel 报表中，**《明细表》**、**《全店汇总表》**、**《销售计划登记表》**及**《每日数据表》**中的数据不再是死数据，而是通过 `SUMIFS` 和 `COUNTIFS` 公式与**《处理表》**及**《推广表》**进行了动态多条件（如商品ID、归属日期）双向绑定。
   - **这意味着：只要您在导出的表格中修改任意一个订单的实收金额、税运费用或更新了《推广表》，相关的综合成本、各子表的产品销售额、全店汇总以及毛利率等数据全都会瞬间自动重算，实现“牵一发而动全身”。**
3. **更灵活的 API 控制与核算**：
   - **新增“查税运”开关**：在 GUI 界面允许用户在只需要基础核算时跳过耗时的 API 请求，大幅提升生成速度。
   - 自动核算千分之六的平台扣点（`0.006 * 商家实收金额`）。
4. **定制化业务子表优化**：
   - 自动生成 **《销售计划登记》** 子表，直观展示各项转化比率，并新增了**税运**与**综合成本**列的展示与公式联动。
   - 针对特定重点产品（如 `dokkan` 和 `movefree`）提取按天拆分的 **《每日数据子表》**，即使单天数据也会生成，并基于“归属日期”实现精准的动态公式匹配。
5. **专业级 Excel 报表排版**：
   - 自动在未销售该产品的店铺明细表中**填充浅灰色占位行**，确保你在切换不同店铺的 Sheet 时，相同产品所在的行数完全对齐，不再跳来跳去。
   - 统一输出为单文件：`[提取自源文件的日期]全店铺销售数据汇总表.xlsx`。
   - 自动合并同一产品的多条链接单元格，自适应列宽，文本左对齐垂直居中，百分比格式化，以及附带浅黄色卡片式高亮底色。

## 如何运行/修改源代码

1. **环境准备**
   确保你安装了 Python (建议 3.8+)。建议使用虚拟环境以避免依赖冲突。

   在项目根目录下，先创建并激活虚拟环境：
   ```bash
   # Windows (CMD / PowerShell)
   python -m venv venv
   .\venv\Scripts\activate
   ```

   激活环境后，安装项目依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. **运行核心核算系统 (桌面 GUI)**
   ```bash
   python gui_batch_query.py
   ```

3. **运行库存配置与查询后台 (Web 端)**
   ```bash
   python flask_admin/app.py
   ```
   运行后，在浏览器访问 `http://127.0.0.1:5000` 即可（同一局域网下的手机也可以通过输入电脑 IP 访问）。

4. **运行图片清洗重命名工具**
   ```bash
   python tools/image_renamer.py
   ```

5. **运行按目录层级重命名工具**
   ```bash
   python tools/dir_file_renamer.py
   ```

6. **打包为 EXE 给业务人员使用**
   *(如果需要打包，请确保已安装 pyinstaller)*
   ```bash
   # 打包核算主系统
   pyinstaller 菜鸟充值订单核算系统.spec
   
   # 打包图片清洗工具
   pyinstaller 图片批量清洗重命名工具.spec

   # 打包层级重命名工具
   pyinstaller -F -w --name="按目录层级重命名工具" tools/dir_file_renamer.py
   ```
   打包完成后，在 `dist` 文件夹中会生成对应的 `.exe` 可执行文件。将该文件发送给使用者即可直接双击运行。

## 业务操作指南

1. 准备好 **成本表.xlsx**、**产品链接汇总表.xlsx**、**官补映射表.xlsx**、**产品汇总表.xlsx** 以及各店铺的 **推广报表.xlsx**。
2. 打开工具，在第一步中多选需要处理的各个店铺的 **订单源数据 (.csv / .xlsx)**。
3. 在第二步中，配置好相关表单的路径（首次配置后会自动记忆）。
4. 填入有效的浏览器 Cookie，可按需设置排除商品ID。
5. 点击“🚀 开始批量处理”。
6. 运行完成后，将在你第一个订单源数据所在的目录下，自动生成最终格式化的 Excel 报表，点击界面底部的蓝色链接即可快速打开文件夹。
