# 菜鸟充值订单批量查询工具

## 项目简介
这是一个基于 Python 开发的桌面 GUI 小工具，主要用于读取业务 Excel 或 CSV 数据，自动批量请求“菜鸟充值订单”接口查询实际金额与费用明细，并结合本地的《成本表.xlsx》自动计算单行毛利，最后将结果带样式回写到表格中。

---

## 核心文件结构

- **`gui_batch_query.py`** (唯一核心主程序)
  包含界面的完整版程序。负责图形界面展示、文件解析（支持批量读取 csv / xlsx）、并发调用查询接口、根据成本表自动计算毛利，并格式化输出多工作表（Sheet）的结果文件。
- **`成本表.xlsx`** (必选依赖文件)
  成本字典文件，程序运行期间会读取它来获取各 SKU 的商品成本（用于核算利润）。若文件中包含名为“母婴奶粉编码”的子表，还会触发特殊税率核算规则。
- **`requirements.txt`**
  运行环境依赖清单，方便其他开发者接手项目时快速配置环境。
- **`菜鸟批量查询工具.spec`**
  PyInstaller 打包配置文件，用于将 `gui_batch_query.py` 编译为免安装的 Windows `exe` 可执行文件。
- **`cookie.txt`** 和 **`exclude_ids.txt`**
  程序自动生成的本地缓存文件，分别用于记忆你上一次填写的登录 Cookie 和需要排除的商品 ID。

*(其他如 `batch_query.py`、`single_query.py`、`test_python.py` 等皆为早期的开发调试脚本，目前不参与主流程业务，可作为接口调试参考)*

---

## 主要功能特性

1. **兼容 CSV 与 Excel 导入**：自动适配读取。如果是 CSV 导入，在内存中也会转换为标准的 Excel 结构，保证输出始终为支持多子表、高亮样式的 `.xlsx` 格式。
2. **状态拦截与自动过滤**：自动识别表头，仅处理“订单状态”为 `已发货，待收货` 和 `已收货` 的记录，并且支持配置“排除商品id”跳过特定商品。
3. **高并发查询**：支持自定义线程数（推荐 4~8 个），利用 `ThreadPoolExecutor` 并发请求菜鸟接口，显著缩短批量查询耗时。
4. **全自动成本与利润计算**：
   - 自动合并订单金额与实际查询金额。
   - 依据配置计算产品成本、订单总成本与综合成本。
   - 智能处理母婴类目特殊的 9.1% 税率算法。
5. **智能化输出**：
   - 将源文件内容追加计算列并导出。
   - 带有**粉色/红色**等样式高亮来标记特殊单据或异常单据（如未找到成本、费用项缺失等）。
   - 自动生成 `汇总` 和 `错误项` 独立工作表。

## 如何运行/修改源代码

1. **环境准备**
   确保你安装了 Python (建议 3.8+)。建议使用虚拟环境以避免依赖冲突。

   在项目根目录下，先创建并激活虚拟环境：
   ```bash
   # Windows (CMD / PowerShell)
   python -m venv venv
   .\venv\Scripts\activate
   
   # macOS / Linux
   python3 -m venv venv
   source venv/bin/activate
   ```

   激活环境后，安装项目依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. **运行程序**
   ```bash
   python gui_batch_query.py
   ```

3. **打包为 EXE 给业务人员使用**
   ```bash
   pyinstaller 菜鸟批量查询工具.spec
   ```
   打包完成后，在 `dist` 文件夹中会生成 `菜鸟批量查询工具.exe`。将该文件发送给使用者即可直接双击运行。

## 业务使用说明

1. 确保将业务所需的源数据（.csv / .xlsx）以及最新的 **`成本表.xlsx`** 放在易于找到的目录。
2. 打开工具，选择你要处理的文件（支持多选）。
3. 填入有效的浏览器 Cookie（可通过浏览器按 F12 抓包获取）。
4. 填写你需要排除的商品ID（可选，使用逗号分隔）。
5. 点击“开始处理”。运行完成后，同一目录下会生成/更新结果文件（如导入的是 CSV，则会生成 `原文件名_处理结果.xlsx`）。
