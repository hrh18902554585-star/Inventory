# 利润核算 Web 服务（profit_service）

## 一、简介

利润核算 Web 服务是原 Excel 桌面程序（`gui_batch_query.py`）的 Web 版：复用同一套核算引擎（`engine.py`），把「选文件、填 Cookie、点运行」的流程搬到了浏览器里。

- 上传成本表、产品链接汇总表、推广报表等配置和订单文件，填写 Cookie 与参数后自动抓取税运接口、核算利润，结果 Excel 一键下载。
- 支持任务排队、进度与日志实时查看、失败重跑，局域网内多人（电脑/手机浏览器）同时使用。
- 技术栈：Python 3.14 + Flask + waitress（waitress 为纯 Python 生产级 WSGI，Windows 下可用；gunicorn 不支持 Windows，本项目不使用）。
- 服务在启动它的那台电脑上常驻运行，浏览器关掉不影响任务继续执行，直到任务跑完。

## 二、快速开始

前置条件：电脑安装 Python 3（推荐 3.14，安装时勾选 Add to PATH）；手机与电脑连接同一 WiFi。

1. **双击 `install_deps.bat`** —— 首次运行只需一次：创建虚拟环境 `venv` 并按 `requirements.txt` 安装依赖。
2. **双击 `start.bat`** —— 启动服务，出现黑色启动窗口（**服务运行期间请勿关闭该窗口**）。
3. 在电脑浏览器打开 **http://localhost:5000**
4. **首次访问时在页面弹出的 Token 输入框里填写启动窗口红字显示的 Token**（见下文「Token 与安全」）。
5. 手机浏览器访问启动窗口显示的「局域网访问」地址，形如 **http://192.168.x.x:5000**（需同一 WiFi）。

如需更换端口：编辑 `start.bat`，取消 `set PORT=xxxx` 一行的注释并改成目标端口（如 8080），保存后重新运行。

## 三、使用指南（四步流程）

1. **上传配置**：在「新建任务 → 1 配置表」上传配置 Excel。
   - 必填：成本表（组合编码/sku成本）、产品链接汇总表（店铺名称/产品名称/商品id）、推广报表（商品ID/总花费(元)）
   - 选填：官补映射表、产品排序表
   - 同一类型可传多版本，系统自动保留最近 10 版，可随时切换或删除。
2. **上传订单**：在「2 订单文件」上传订单文件，支持 `.csv` / `.xlsx`，单个不超过 10MB，可一次多选。
3. **填写参数**：在「3 参数」填写
   - **Cookie**（必填）：菜鸟后台的登录 Cookie，可在此处保存，之后任务直接使用
   - 线程数：2~4，越大抓取越快
   - 是否查税运：开关
   - 排除订单 ID：不需要核算的订单号
4. **处理并下载**：确认摘要后提交，进入任务详情页实时查看进度与日志（每 2 秒自动刷新），完成后点击「下载」获取结果 Excel。

其他：任务总览/历史记录页支持**重跑**（复用原参数）与**删除**（仅已完成/失败的任务可删）；同一时间最多 2 个任务并行，排队上限 10 个。

## 四、Token 与安全

- **为什么需要 Token**：服务监听 `0.0.0.0`，同一 WiFi 内任何设备都能访问页面。Token 用于防止未授权的人上传文件、提交任务。
- **Token 从哪来**：首次启动时自动随机生成，显示在启动窗口（红字），同时写入 `data/token.txt`。浏览器首次访问页面时会弹出输入框，填入后保存在该浏览器内，之后无需重复输入。
- **忘记 Token**：用记事本打开 `profit_service\data\token.txt` 查看。
- **安全提醒**：本服务没有 HTTPS 加密，Cookie 与 Token 均在局域网内明文传输，请仅在可信 WiFi 环境使用；日志中的 Cookie、订单号会自动脱敏（`security.sanitize`）。

## 五、常见问题（FAQ）

| 现象 | 处理办法 |
| --- | --- |
| 启动报错或页面打不开 | 端口被占用。改端口：编辑 `start.bat` 加 `set PORT=8080` 后重跑，或先关闭占用 5000 端口的程序 |
| 手机打不开页面 | 确认手机与电脑同一 WiFi；检查 Windows 防火墙是否放行了 Python（首次启动时选择「允许访问」） |
| 任务全部标红失败 | 多半是 **Cookie 过期**：重新在浏览器登录菜鸟后台复制最新 Cookie，在「参数」步骤粘贴保存，然后点「重跑」 |
| 上传提示「不支持的文件类型 / 文件过大」 | 仅支持 `.csv` / `.xlsx`，单个 ≤10MB；配置表还需包含必要表头（如成本表需有「组合编码」「sku成本」），按提示修正后重传 |
| 任务失败但页面日志看不明白 | 打开 `data\logs\app.log` 查看系统日志（自动轮转，单文件最大 5MB，保留 5 个） |
| 忘记 Token | 见 `data\token.txt` |
| 页面白屏 | 用浏览器无痕窗口重新打开；确认访问的是 http 而非 https |

## 六、数据目录说明（profit_service\data\）

| 目录/文件 | 用途 |
| --- | --- |
| `app.db` | 任务数据库（任务记录、日志、状态），**重要数据** |
| `configs/` | 上传的配置表，按类型分子目录（cost/link/promo/subsidy/sort），版本化管理 |
| `uploads/` | 上传的订单文件 |
| `tasks/<任务id>/inputs/` | 每个任务的输入快照（订单+配置的副本） |
| `outputs/` | 任务产出的结果 Excel |
| `cookie.txt` | 页面保存的 Cookie |
| `token.txt` | 访问 Token（勿外传） |
| `logs/app.log` | 系统日志 |
| `stats.json`、`tax_cache.json` | 统计指标与税运缓存，可删除，会自动重建 |

**备份 = 复制整个 `data/` 目录**（建议先关闭服务再复制，保证文件完整）；空间有限时最少复制 `app.db + configs/` 即可保留全部历史任务与配置，其余目录会自动重建。

## 八、升级 / 重启

- **升级**：先备份 `data/` → 用新版文件覆盖 `profit_service/`（保留 `venv/` 与 `data/`）→ 重新双击 `start.bat`。依赖有变化时先重跑 `install_deps.bat`。
- **重启说明**：服务重启（或电脑重启后重开 `start.bat`）时，所有运行中/排队中的任务会自动标记为**失败（原因：进程中断）**；已完成的任务与结果文件不受影响。重启后对这些失败任务点「重跑」即可重新执行。
