# 利润核算 Web 服务 — 模块接口契约 V1.0

> 30 个开发智能体并行开发的接口基准。**所有模块必须严格遵循此契约**，禁止自行发明接口。
> 除标注 [可选] 外，所有接口必须实现。

tasks 表 DDL：
```sql
CREATE TABLE IF NOT EXISTS tasks (
  id TEXT PRIMARY KEY,
  status TEXT NOT NULL DEFAULT 'pending',   -- pending/running/done/error
  progress REAL DEFAULT 0,
  status_text TEXT DEFAULT '',
  params_json TEXT NOT NULL DEFAULT '{}',   -- {order_files:[ids], configs:{type:version}, cookie, thread_count, enable_tax, exclude_ids}
  result_files_json TEXT DEFAULT '[]',      -- 输出文件名列表（相对 outputs/<id>/）
  log_json TEXT DEFAULT '[]',
  created_at TEXT, finished_at TEXT,
  error TEXT DEFAULT ''
);
```

## 6. task_manager.py

```python
MAX_CONCURRENT = 2
def init_task_manager() -> None              # ThreadPoolExecutor(2) + db.mark_interrupted_tasks()
def submit_job(params: dict) -> (str, str|None)
    # 校验: cookie 非空、订单文件≥1、必填配置齐全（用 configs.resolve_configs）
    # 通过: 快照输入 → 建任务(pending) → executor.submit(run_job) → 返回 (task_id, None)
    # 失败: 返回 (None, 错误文案)
    # 排队: 直接 submit（Executor 自带队列），上限 10 个排队任务，超出拒绝
def get_job(task_id) -> dict | None
def list_jobs() -> list[dict]
def delete_job(task_id) -> (bool, str)       # 仅 done/error；删除任务记录+outputs目录
def rerun_job(task_id) -> (str, str|None)    # 复用 params_json 重建任务（新 id）
def get_download_path(task_id, filename) -> str | None  # 校验 filename 在 outputs/<id>/ 内
def run_job(task_id) -> None                 # 内部: pending→running→调 engine.process→done/error
    # 引擎回调: log(msg) → append_log + 日志文件；progress(pct,text) → update_task
    # tax_cache: 任务结束后 force_flush；tax_cache 全局共享
    # 输出: engine 返回 files → 复制/保持到 outputs/<id>/ 并更新 result_files_json
def cleanup_outputs(max_age_hours=24) -> None  # 启动时清扫
```

任务日志：内存环形缓冲由 db.log_json 承担（SQLite 读写即可，量小）；无需额外 deque。

## 9. app.py（Flask 路由）

鉴权：除 `/`、`/static/*` 外全部要求 X-Api-Token（401 + {"code":1,"message":"未授权"}）。
统一响应：成功 {"code":0,"data":...}；失败 {"code":xxx,"message":"中文"}。

```python
def create_app() -> Flask
# 路由:
#   GET  /                     → render_template('index.html')
#   GET  /api/cookie           → {"cookie_valid": bool, "masked": "ab***gh", "updated_at"} (不回传明文；valid 恒 False 也行，仅提示)
#   POST /api/cookie           → 存 cookie.txt（data/cookie.txt），返回 {"success": true}
#   GET  /api/configs          → list_configs() 包装
#   POST /api/configs/upload   → multipart: type + file → save_config + validate_on_upload
#   DELETE /api/configs        → ?type=&version= → delete_config
#   POST /api/uploads          → multipart: file（多个文件时前端逐个传）→ save_order_file
#   GET  /api/uploads          → list_order_files()
#   DELETE /api/uploads/<id>   → delete_order_file
#   POST /api/jobs             → json: {order_files:[ids], configs:{type:version}, cookie, thread_count, enable_tax, exclude_ids} → submit_job
#   GET  /api/jobs             → list_jobs()
#   GET  /api/jobs/<id>        → ?since=N → {task 字段..., logs: get_logs(since)}
#   POST /api/jobs/<id>/rerun  → rerun_job
#   DELETE /api/jobs/<id>      → delete_job
#   GET  /api/jobs/<id>/download/<filename> → send_from_directory(outputs/<id>, filename)
#   GET  /api/stats            → get_stats()
# 错误码: 1 未授权, 2 参数错误, 3 配置缺失, 4 任务不存在/非法, 5 上传校验失败, 6 服务忙(排队满)
# 启动时: init_db + load_cache + init_task_manager + cleanup
```

## 11. 前端契约（templates/index.html）

Vue2 + Element UI 2.15.14（static/ 下 CDN 本地文件），axios。单页三视图（v-show 切换）：
- 视图1 任务总览：运行中任务进度 + 最近任务列表 + "新建任务"按钮
- 视图2 新建任务：4步向导（el-steps）：
  1. 配置表（GET /api/configs 展示状态，el-upload 自定义 http-request 上传，必填引导）
  2. 订单文件（el-upload 多选 + 列表展示）
  3. 参数（Cookie textarea / 线程 slider 2-4 / 查税运 switch / 排除ID 标签输入）
  4. 摘要 → POST /api/jobs → 跳任务详情
- 视图3 历史记录：任务表格（状态 tag / 时间 / 下载 / 重跑 / 删除）
- 任务详情（可复用视图1卡片或弹层）：el-progress + 日志区（2s 轮询 GET /api/jobs/<id>?since=N，增量追加，上限 2000 条截断）+ 完成下载按钮（axios blob）
- 全局：axios 拦截器统一错误（code→el-message）；visibilitychange 暂停轮询；提交防重复
- token：登录弹层（el-input password，存 localStorage "api_token"，axios 拦截器统一加头）
